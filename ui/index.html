    3. Rust の作業フォルダ（target）

    消すとどうなる？（読むと安心です）
    途中の記録（incremental）
    自分のコードを少しだけ直したときに速くビルドするための記録です。消しても、次のビルドで自分のコードを1回だけ全部作り直すだけです（目安：数十秒〜数分）。ダウンロードした部品は作り直しません。いちばん安全に減らせます。
    debug / release を消す
    そのビルドの結果を全部消します。次のビルドで部品から全部作り直します（目安：数分〜十数分）。作った exe も消えるので、残したい exe は先に別の場所へ写してください。
    全部消す
    target フォルダごと消します。「cargo clean」と同じです。ソース（src や Cargo.toml）には触りません。
    消さないとき
    その中のプログラムが動いているときと、ビルド中のときは消しません。VS Code の rust-analyzer が使っているファイルは消せずに残ることがあります。

    4. Cargo のダウンロード置き場

    すべての Rust プロジェクトで共通に使う、ダウンロードした部品の置き場です。
