# Rust 容量そうじ

Rust のビルドでたまる作業フォルダ（cargo が作る `target`）と、Cargo のダウンロード置き場を見つけて、容量を減らす Windows 用のアプリです。Python・JS などのプロジェクトも言語を見分けて、消しても大丈夫なものだけを消せます。

## ダウンロード

[Releases](https://github.com/hhurt21/project-delete-/releases) から `rust-cleaner.exe` をダウンロードして開くだけです。インストールは要りません。

- Windows 10 / 11 用です。画面の表示に Microsoft Edge WebView2 を使います（Windows 11 には最初から入っています）
- 署名していない exe なので、初めて開くときに SmartScreen が出ることがあります。「詳細情報」→「実行」で開けます
- 消したものは、ごみ箱に入らずにすぐ消えます。消す前の確認の窓をよく読んでください

## 使い方

1. 開くと「1. プロジェクトの容量」が自動で測られます。置き場は「置き場を変える」で選べます（はじめは `D:\claude`、無ければユーザーのフォルダ）
2. いちばん安全なのは「全プロジェクトの「安全」をまとめて消す」です。キャッシュと Rust の途中の記録だけを消します
3. 詳しく見たいフォルダは「詳しく見る」で開きます。「手間あり」は1つずつ、戻し方を読んでから消してください

## できること

| 機能                       | 内容                                                                                                            |
| -------------------------- | --------------------------------------------------------------------------------------------------------------- |
| 探す                       | 選んだ場所（既定はユーザーのフォルダと C 以外の内蔵ドライブ）から `target` を探して、大きい順に並べます         |
| 途中の記録だけ消す         | `incremental` だけ消します。次のビルドで自分のコードを1回作り直すだけで、部品は作り直しません。いちばん安全です |
| debug / release を消す     | そのビルドの結果を全部消します。次のビルドは部品から作り直しです                                                |
| 全部消す                   | `target` ごと消します（`cargo clean` と同じ）                                                                   |
| まとめて消す               | 見つけた全部の作業フォルダから、途中の記録をまとめて消します                                                    |
| Cargo のダウンロード置き場 | `~/.cargo/registry` と `~/.cargo/git` の中身を測って、消せます                                                  |

## プロジェクトの容量（言語ごとの片づけ）

プロジェクトの置き場（既定は `D:\claude`）の中を、フォルダごとに測ります。言語（Rust・Python・JS・C#・Java・Go）の印を付け、片づけられるものを3段階で出します。

| 段階     | 中身                                                                                                                                              | 消し方                                                      |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| 安全     | Python のキャッシュ（`__pycache__`・`.mypy_cache`・`.pytest_cache`・`.ruff_cache`）、JS のキャッシュ（`.next`・`.turbo` など）、Rust の途中の記録 | 1つずつ、プロジェクトごとにまとめて、全プロジェクトまとめて |
| 手間あり | Rust の `target`、Python の `.venv`、`node_modules`、PyInstaller・Nuitka の途中のファイル、C# の `obj`、Gradle の `.gradle`                       | 1つずつ（戻し方のコマンドも出します）                       |
| 見るだけ | `release`・`dist`・`out`・`bin`・`build` のうち、上のどれでもない部分（10 MB 以上）                                                               | 消しません。フォルダを開くだけ                              |

見分けは名前だけでなく、中身や親フォルダの印でも確かめます（例：`.venv` は `pyvenv.cfg`、`node_modules` は隣の `package.json`、PyInstaller は `PYZ-00.toc`、Nuitka は `.sconsign` のファイル）。`.venv` と `node_modules` は、戻し方（`requirements.txt`・`pyproject.toml`・`uv.lock`・`package.json`）が見つからなければ消させません。

## 安全のための決まり

- 「探す」や「プロジェクトの容量」で見つけて「消せる」と出したもの以外は消しません。消す直前にもう一度見分けて、中身が変わっていたら消しません
- `__pycache__` は、中が `.pyc` だけのときしか消しません
- その中のプログラム（`.venv` の python.exe など）が動いているときは消しません
- 「探す」で見つけた `target`（cargo の印 `CACHEDIR.TAG` があるもの）以外は消しません
- その中の exe が動いているとき、ビルド中（`.cargo-lock` が使われている）のときは消しません
- Cargo の置き場は、cargo / rustc が動いている間は消しません
- 使用中で消せないファイルは飛ばして、数と例を出します
- 空いた量は、ドライブの空きを消す前と後で測った実際の値で出します

## ビルド

```
cd src-tauri
cargo build --release
```

exe は `src-tauri\target\release\rust-cleaner.exe` にできます（`build.bat` でも同じ）。Node.js や Tauri CLI は要りません。

設定（探す場所）は `%APPDATA%\rust-cleaner\settings.json` に保存します。
